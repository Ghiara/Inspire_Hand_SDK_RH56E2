REFERENCE / 01

使用约定

先确认顺序、单位与执行周期，再选择控制器。

本文对应仓库当前 Python 实现，覆盖 SDK 的公共方法、构造参数、状态与返回对象。下划线开头的内部辅助方法不作为公共 API。四种模式 controller 均继承 GeneralController；同一个后端应由一个控制循环发布命令。

通道、单位与模型边界

下标 通道 主动关节 位置范围 / rad
0 pinky pinky_joint 0..1.4381
1 ring ring_joint 0..1.4381
2 middle middle_joint 0..1.4381
3 index index_joint 0..1.4381
4 thumb_bend thumb_joint2 0..0.5864
5 thumb_rotation thumb_joint1 0..1.1641

上述为便于阅读的近似值；准确边界由 HandModel.lower / upper 从 URDF 与 mimic 约束计算。6 轴数组按 CHANNELS 排序，5 指数组按 FINGERS = (pinky, ring, middle, index, thumb) 排序。所有向量必须形状正确且值有限。

位置使用 rad，带方向速度使用 rad/s，指尖 xyz 使用 m，固定坐标系为 hand_base。正速度朝关节角增大方向运动。模型 0 rad 是展开；设备角度 1000 是展开，0 是弯曲。12 个活动关节只有 6 个主动轴：四指 DIP 比例 1.0843，拇指 joint3 / joint4 相对 joint2 的比例为 0.8024 / 0.76123688。

最大主动速度由主动与被动关节的限位共同决定：四指约 0.9223 rad/s，拇指两轴 1 rad/s。越界的用户输入会被拒绝；积分控制产生的内部参考在边界饱和。

控制循环与模式切换

操作 发布命令 推进仿真 / 等待真机 返回
position.set_targets / set_finger / set_joint 是 否 六轴目标 ndarray
cartesian.solve 否 否 IKResult
cartesian.set_targets 求解成功后发布 否 IKResult
velocity.set_targets 否，仅设置速度与参考 否 六轴速度 ndarray
velocity.update(dt) 积分并发布一次 否 六轴位置参考 ndarray
velocity.step(dt) 积分并发布一次 是 None
force.set_targets 否，仅初始化反馈控制状态 否 None
force.step(dt) 闭环调整并发布一次 是 None
advance(dt) 不产生新的模式目标 是 None
open_hand / return_to_zero / move_to_positions 周期发布位置参考 是，阻塞直到反馈到位 HandState

不要在 step(dt) 后为同一个周期再调用 advance(dt)。仿真 advance 必须是 0.001 秒的正整数倍；真机 advance 只做 time.sleep，不驱动新的控制更新。切换模式前结束旧循环，再调用 hand.stop() 清除旧积分状态。stop() 为当前位置保持请求，不是断电急停；close() 只释放资源，不隐式调用 stop()。

最小示例 

from inspire_sdk import InspireHand

with InspireHand.simulation(side="left") as hand:
    hand.position.set_finger("index", 0.5)
    hand.advance(2.0)
    print(hand.read_state().to_dict())

    hand.stop()
    hand.velocity.set_targets([0, 0, 0, 0.1, 0, 0])
    for _ in range(100):
        hand.velocity.step(0.01)
    hand.stop()

InspireHand

统一入口：工厂、控制器实例与资源管理。

from inspire_sdk import InspireHand

属性 backend 为所选后端；general、position、velocity、force、cartesian 分别为绑定同一后端的五个 controller 实例。支持 with 上下文，退出时只调用 close()。

GeneralController

四种模式共同继承的读取、保持与到位等待逻辑。

from inspire_sdk import GeneralController, MotionCancelled, PoseTimeoutError

源码 ↗ 
GeneralController.open_hand(**kwargs)

GeneralController.return_to_zero

源码 ↗ 
GeneralController.return_to_zero(**kwargs)

将设备语义的 [0, 0, 0, 0, 0, 1000] 转为模型角度并等待到位。

参数

名称 类型 / 单位 默认值 说明
kwargs 关键字参数 透传 同 move_to_positions() 的可选参数，但禁止传 hold_channels。timeout_s 约束整个回零流程，包含可能的拇指旋转预恢复阶段。

执行细节

若拇指旋转还未展开，先保持另外五轴测量姿态、单独恢复旋转，再将该轴从第一条闭合命令起锁在展开目标，移动另外五轴。这里的设备“零”不是六轴模型 0 rad。

GeneralController.move_to_positions

源码 ↗ 
GeneralController.move_to_positions(positions_rad, *, rate_rad_s=0.2, period_s=0.05, timeout_s=30.0, tolerance_rad=0.01, settle_samples=3, tolerance_units=20.0, on_state=None, on_progress=None, cancelled=None, hold_channels=())

按每周期最大 rate_rad_s × period_s 插补六轴参考，最终参考发出且所有轴连续到位后返回。等待的是反馈到位，而非写应答。

参数

名称 类型 / 单位 默认值 说明
positions_rad array-like (6,) / rad 必填 六轴目标，须在有效机械边界内。
rate_rad_s float / rad/s 0.2 有限正数，每轴参考最大变化率；不能超过任何轴的 URDF 速度上限。
period_s float / s 0.05 有限正数；仿真须为物理步长的整数倍。
timeout_s float / s 30.0 整个单次移动的墙钟超时，有限正数。
tolerance_rad float / rad 0.01 有限正数，仅仿真模型反馈比较使用。
settle_samples int 3 连续到位样本数，必须为正整数，不能是 bool。
tolerance_units float / 设备单位 20.0 真机 ANGLE_ACT 原始值容差，范围 (0, 1000]；SDK 范围与 demo CLI 的 1..50 不同。
on_state callable | None None on_state(state: HandState, reference: ndarray(6,))；在 on_progress 之后调用，reference 为副本。返回值忽略。
on_progress callable | None None on_progress(diagnostics: dict)；每周期读取反馈后调用，字段见下表。返回值忽略。
cancelled callable | None None 无参回调，返回真值时中止；在初次读取前、周期写入前及回调后检查。
hold_channels collection[str] () 从第一条命令起固定为目标的主动通道。初始反馈必须已在容差内；不能传单个字符串。

返回

HandState：满足连续到位条件的最终采样。

异常

ValueError：向量 / 边界 / 速度 / 时长 / 容差 / 保持通道不合法；RuntimeError：设备反馈有故障或 ANGLE_ACT 丢失；MotionCancelled：取消；PoseTimeoutError：等待超时；后端异常或回调异常原样传播。

执行细节

开始时重置本 controller 状态，以测量姿态裁剪到机械边界作为插补初值。慢 I/O 不会导致补偿性的大步跳变。真机直接比较 raw_angles 与映射后的原始目标，仿真比较 positions_rad。最终参考未发出时不累计到位。写入尝试之后发生异常或中断，会尽力保持当前位置并重新抛出原异常；保持本身仍可能失败。

state = hand.general.move_to_positions([0, 0, 0, 0.3, 0, 0], rate_rad_s=0.1, timeout_s=15)

on_progress 字典与运动异常

字段 内容
source / units 真机 ANGLE_ACT / native_units；仿真 model_joint_feedback / rad。
target / actual / absolute_error 对应比较单位的六轴目标、反馈与绝对误差列表。
tolerance / blocking_channels 本次容差 / 仍超过容差的通道名列表。
final_reference_sent 当前插补参考转为比较单位后是否等于最终目标。
settled_samples / required_samples 当前连续到位次数 / 要求次数。
held_channels 本次固定的通道名列表。
raw_forces / peak_raw_forces 六路原始力值 / 截至当前各通道的最大采样值；仿真为 None；不是 N。
commanded_force_limits 本后端最近设置的设备力阈值，或 None。

MotionCancelled 继承 RuntimeError。PoseTimeoutError 继承 TimeoutError；feedback 为超时前最近一次比较字典的副本，diagnostics 保存保持命令之前尽力采集的反馈、原始峰值、错误码及设备寄存器快照（或读取错误）。这些诊断不证明机械到位。

网络配置 CLI

IP 读取、修改与 Flash 保存独立于运动控制。

network_config.py 不导入运动控制模块；默认只读，不扫描设备、不修改电脑网口、不自动重启。下面的参数用于此独立入口，不是 InspireHand.modbus_tcp() 的参数。

完整命令参数

参数 默认值 说明
--host 192.168.11.210 当前连接 IPv4，须为可用单播地址；写入时仍填写旧地址。
--port 6000 TCP 端口，1..65535。
--device-id 255 TCP Unit ID，1..255。
--timeout 2.0 有限正请求超时秒数；默认客户端 retries=0。
--set-ip 未设置 新 IPv4；只有提供此参数才写设备 IP。
--save False 必须与 --set-ip 同时使用；回读通过后请求全局 Flash 参数保存。
--network-only False 只读本机网口和路由，不连接设备；不能同时 --set-ip。
--ip-layout auto auto / packed-le / packed-be / octet；显式布局须已根据固件核实。 
# 读取
python network_config.py --host 192.168.11.210
# 修改，不保存
python network_config.py --host 192.168.11.210 --set-ip 192.168.1.210
# 修改并请求保存
python network_config.py --host 192.168.11.210 --set-ip 192.168.1.210 --save
# 已核实 packed-le 的设备，保存已修改但待生效的配置
python network_config.py --host 192.168.11.210 --set-ip 192.168.1.210 --ip-layout packed-le --save
# 手动重新上电、电脑网口可访问新网段后确认
python network_config.py --host 192.168.1.210

寄存器编码与保存行为

设备 IP 起始地址为 1700。packed-le / packed-be 将四个字节按小端 / 大端打包为两个 16-bit 寄存器；octet 使用四个寄存器分别存一个字节。auto 仅通过读取与 --host 比对，并独立核对 1702，不能唯一确认时拒绝写入。修改后先回读目标 IP。

保存地址为 1005：packed-be 写 0x0100，其他布局写 1，保持相邻 RESET_PARA 字节为 0。保存前后均回读 IP；设备已经是目标 IP 时跳过重写但仍可请求保存。请求后预留 2 秒等待，不将应答或等待当作持久化证明。保存作用于当前可保存的全局参数；手动重新上电后应使用新地址再次读取。

脚本返回码：0 表示当前流程完成，1 表示导入 / 通信 / 配置失败，130 表示中断，argparse 参数错误通常为 2。失败后不自动重试、不自动回滚。
